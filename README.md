# 🚀 DevSpace — Developer Portfolio Website

A simple, modern, and responsive developer portfolio landing page built using **HTML, CSS, and JavaScript**. This project was created primarily for testing, practice, and learning purposes to understand the fundamentals of front-end web development.

DevSpace provides a clean interface with a modern dark theme, a light mode toggle, interactive buttons, and feature cards introducing the core technologies used to build websites.

This project is an early step in exploring web development, improving coding skills, and learning how different front-end technologies work together to create an interactive website.

---

## 📌 About the Project

DevSpace is a small static website designed to experiment with the basic concepts of front-end development.

The primary goal of this project was not to build a fully functional professional portfolio, but to practice writing HTML, styling elements with CSS, and implementing basic interactions using JavaScript.

While building this project, I explored how to structure a webpage, connect multiple files, design a responsive layout, handle button click events, and modify the appearance of a website dynamically.

This project serves as a beginner-friendly practice project and a foundation for building more advanced web applications in the future.

## ✨ Features

- **Modern UI:** A clean and minimal interface with a developer-focused design.
- **Dark Theme:** A dark background with purple accents for a modern appearance.
- **Light and Dark Mode Toggle:** Switch between dark and light themes using JavaScript.
- **Interactive Buttons:** Functional buttons that respond to user interactions.
- **Smooth Scrolling:** Navigate to the technology cards with a smooth scrolling effect.
- **Responsive Layout:** The layout adapts to smaller screens using CSS media queries and flexible containers.
- **Technology Cards:** Dedicated cards introducing HTML, CSS, and JavaScript.
- **Simple Code Structure:** Separate files for HTML, CSS, and JavaScript to keep the project organized.
- **Beginner-Friendly:** Easy-to-understand code that can be modified and extended.
- **No External Dependencies:** The website uses standard HTML, CSS, and vanilla JavaScript without requiring a front-end framework.

## 🛠️ Technologies Used

### 1. HTML5

HTML is used to define the structure and content of the website.

It provides the navigation bar, hero section, headings, buttons, technology cards, and footer. The HTML document also links the stylesheet and JavaScript file.

### 2. CSS3

CSS is responsible for the visual design and layout.

It is used for:

- Colors, typography, and spacing.
- Flexbox-based layouts.
- Card styling, borders, and rounded corners.
- Hover effects and transitions.
- Responsive design using media queries.
- Light theme styling through CSS classes.

### 3. JavaScript

Vanilla JavaScript adds basic interactivity to the website.

It handles:

- Dark and light theme switching.
- Button click events.
- Dynamic text updates.
- DOM manipulation.
- Smooth scrolling to the technology cards.

## ⚙️ How It Works

### Website Structure

The `index.html` file defines the main sections of the webpage. It includes the navigation bar, introductory hero section, technology cards, and footer.

The HTML file connects the stylesheet through a `<link>` element and loads JavaScript through a `<script>` element.

### Styling and Layout

The `style.css` file controls the overall appearance of the website. Flexbox is used to align elements, while CSS properties control spacing, typography, backgrounds, borders, and hover effects.

A media query adjusts the layout for smaller screens so the technology cards can fit mobile devices more effectively.

### Theme Switching

The theme toggle uses JavaScript to add or remove the `light` class from the document's body.

CSS rules then change the background, text colors, and card appearance based on whether the light theme is active.

### Interactive Button

When the user clicks the Explore More button, JavaScript updates a message on the page and scrolls smoothly to the technology cards.

This demonstrates how JavaScript can respond to user actions and dynamically change webpage behavior without reloading the page.

## 🚀 Getting Started

You can run this project locally on your computer by following these steps.

### Prerequisites

You will need:

- A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
- A code editor such as Visual Studio Code.
- The Live Server extension for VS Code (optional, but recommended).

### Installation

**Step 1: Clone the repository**

Open your terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the actual URL of your GitHub repository.

**Step 2: Navigate to the project directory**

```bash
cd DevSpace
```

**Step 3: Open the project in VS Code**

```bash
code .
```

**Step 4: Run the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for local development.

That's it! The website should now be running locally.
